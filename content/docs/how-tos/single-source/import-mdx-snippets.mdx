# Import MDX Snippets

Use shared MDX snippets when several pages need the same warning, example, or setup step. Keep the reusable snippet close to the source documentation, then import it into the pages that need it.

## Recommended Pattern

1. Create a small MDX file for the reusable content.
2. Export the snippet as a component.
3. Import the snippet into each page that needs the same content.

This keeps repeated documentation consistent without copying the same text into multiple pages.
