# Quickstart

The Getting Started section is designed to help new users quickly install and begin using the DOCS software. Here, you'll find step-by-step instructions for setting up your environment and running your first example.

## What to Expect

- Guidance on installing the necessary dependencies
- A simple "Hello World" example to demonstrate basic usage
- Tips for verifying your installation and exploring further features

Follow the instructions below to get up and running with DOCS in just a few minutes.
